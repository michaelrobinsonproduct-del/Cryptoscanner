# Prospective metrics

Primary: recall of eventual +20%, +50%, +100% movers and lead time before threshold crossing.

Guardrails: false-positive rate; alert displacement buckets <=3%, <=5%, <=10%; data freshness; coverage; candidate-specific WS/REST confirmation success; stale/asynchronous quote rejection; system availability.

Control and challenger are evaluated on the same observation windows. Historical results can train/test hypotheses but cannot count as prospective wins.
