# Definition of done

The replacement is not done merely because it runs. Before production promotion it must pass deterministic scanner/evaluation tests; preserve or improve market coverage and data freshness; demonstrate prospective evidence rather than historical hindsight; independently confirm Kraken execution twice; reject stale/asynchronous cross-venue evidence; measure extension from discovery baseline; retain failed-validation discoveries as WATCH; produce reproducible release metadata; preserve rollback; and compile the iOS cockpit without embedding secrets.

Prediction accuracy can never be guaranteed at 100%. Infrastructure gates are designed to fail closed when evidence is stale or incomplete.
