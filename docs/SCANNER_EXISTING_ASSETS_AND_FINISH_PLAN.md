Display numerical baseline/challenger scores, price, quote timestamp, 15m momentum, volume acceleration, risk and WATCH/ABSTAIN. Keep missing-proof outcomes explicit and visible, not silent success.

Check reliability over multiple scheduled runs. Then obtain explicit authorization before any production change.

## Do not confuse these
- Run 41945108092 proves **real scan and candidates**, not durable production ledger publication, independent D verification or B delivery.
- A passing integration merge/test workflow proves **code composition**, not end-to-end operational correctness.
- A successful isolated test does not imply authenticated historical trade data or qualified 30% learning improvement.
- The existing quota-limited Codex coding workflow cannot autonomously finish while its API quota is exhausted; GitHub Actions alone cannot invent missing implementation. The best no-API route is direct GitHub code changes on existing owner PRs, plus GitHub Actions for deterministic execution and evidence.
