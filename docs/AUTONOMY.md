# Autonomous improvement contract

The system is optimized for prospective early identification, not preserving a favored architecture. It may replace challenger algorithms when evidence warrants. It should automatically diagnose verified misses, generate a generalizable hypothesis, implement the smallest challenger change, run deterministic tests and historical regression, collect prospective shadow evidence, compare against the unchanged control, and promote only through the release gate.

No post-move detection is counted as a win. A change that merely increases alert volume without improving prospective recall/lead time is not an improvement.
